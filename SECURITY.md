# Segurança

O TWC altera configurações de rede e executa como root após autenticação pelo
PolicyKit. Use-o apenas em sistemas e interfaces que você tem autorização para
administrar. Considere desconexões como efeito esperado de algumas ações.

## Relatar uma vulnerabilidade

Não publique detalhes de uma vulnerabilidade ainda não corrigida em uma issue
pública. Envie uma descrição privada para **benyvan@gmail.com** com o assunto
`TWC security report`. Inclua a versão, distribuição, impacto e passos mínimos
para reproduzir. Não inclua senhas nem dados de terceiros.

O mantenedor confirmará o recebimento e combinará uma divulgação responsável.
Não há SLA de resposta ou programa de recompensa de segurança.

## Versões

Até a publicação de uma versão estável no GitHub, não há garantia de suporte
ou atualização de segurança. Ao relatar, informe a versão exibida pelo pacote
e se o programa foi instalado pelo `.deb` ou executado a partir do código.
